## What EggSpread Time Reserver Does

EggSpread Time Reserver gives groups a shared way to work out when everyone is available for a hangout. Instead of managing possible times across separate messages, participants can use a scheduling-focused view to identify workable options and settle on a plan.

The application runs in a web browser, so it does not require a platform-specific desktop program. Its workflow is centered on collecting availability, comparing possible times, and reserving time for social activities.

1. Launch EggSpread Time Reserver in a web browser.
2. Create or open a scheduling session for the hangout.
3. Enter available times or inspect the times already provided.
4. Compare the entries from the other participants.

6. Revisit the session later if the arrangement changes.
